# QuizzCraft.app // 3D Kinetic Neural Quiz Realms

A Next.js application recreating the QuizzCraft 3D Animated Redesign homepage.

## Features Included

- **Cosmic Parallax Canvas**: Multi-tiered particle starfield with real-time mouse coordinate and scroll offset displacement physics.
- **3D Perspective Tilt Card**: Dynamic interactive card tracking mouse cursor with stacked shadow cards, live countdown, instant multiple-choice evaluation, and floating streak XP toast animations.
- **Synthesized Web Audio API**: Tactile audio feedback for button interactions, correct answer bells, and scanner simulation (no external media files required).
- **Interactive PDF Laser Dropzone**: Simulated laser ingestion with animated progress meters and real-time concept vector status updates.
- **Chapter Progress Navigation**: Fixed glassmorphic navigation bar with scroll-spy tracking chapters 01 through 05.
- **Bento & Persona Grids**: Kinetic feature bento grid and modular workspace cards.

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd D:\Aryan\coding\vide\quizzcraft-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
